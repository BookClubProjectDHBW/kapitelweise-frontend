# Kapitelweise – Frontend

Kapitelweise hilft Buchclubs, sich zu organisieren: Bücher vorschlagen, gemeinsam das nächste Buch auswählen und Treffen planen, alles an einem Ort statt im Gruppenchat.

Dieses Repo enthält die Oberfläche, die man im Browser sieht. Es gibt sie in zwei Varianten:

- Startseite (Angular): Hier sieht man seine Buchclubs und offenen Einladungen, kann einen neuen Club gründen und Einladungen annehmen oder ablehnen.
- Login, Registrierung und Buchclub-Seite (HTML, CSS, JavaScript): Auf der Buchclub-Seite sucht man Bücher, schlägt sie vor, sieht das aktuelle Buch und sagt zu Treffen zu oder ab. Admins können außerdem Mitglieder einladen, das nächste Buch auswählen und Treffen anlegen.

Die Seiten funktionieren auch auf Handy und Tablet.
